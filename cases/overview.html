  1. 阶段一：现场勘测与拓扑规划
    • 梳理现场传感器、仪表、PLC、网络摄像机的物理布线走向；
    • 划分网络网段（工控网 VLAN 与安防监控网 VLAN），根据视频路数规划核心交换机背板带宽（每路 4K H.265 按 4~6 Mbps 预留）。
  2. 阶段二：协议接入与物模型统一建模
    • 登录 MzMedia 控制台，基于产品模版建立统一物模型（TSL）；
    • 使用在线工具校验 Modbus 点位大端/小端字节序（ABCD / CDAB），配置 GB28181 SIP 接入鉴权密码并完成摄像机通道自动目录发现。
  3. 阶段三：TCA 规则与 Spring AI 智能体联调
    • 配置 Trigger（属性上报/状态跳变）与 Condition（多条件与生效时段）；
    • 绑定 Action（下发预置位 0x81、开始云端录像、触发反控继电器）；
    • 挂载 Spring AI 多模态视觉复核模型或时序 RAG 工具链，过滤物理误报。
  4. 阶段四：业务协同闭环与持续进化
    • 打通协同矩阵：对接企业微信/钉钉 Webhook 告警机器人，打通 MES 维保派工单与 WMS 备件虚拟锁定；
    • 持续将设备原厂维保手册注入 Spring AI 知识库，使系统自愈与排障决策日益精准。

为什么提示 "giscus is not installed on this repository"？

Giscus 是基于 GitHub Discussions 的开源评论组件。因为当前仓库 MzMedia/MzMedia.github.io 尚未在 GitHub 启用 Discussions 功能或未授权 Giscus App，直接加载会提示该错误。

🛠️ 仓库管理员 2 分钟极速开通指引：

  1. 开启 Discussions：访问 GitHub 仓库设置 (Settings) ，找到 Features 勾选 Discussions。
  2. 授权 Giscus App：打开 github.com/apps/giscus ，点击 Install 并授权给仓库 MzMedia/MzMedia.github.io。
  3. 获取 Category ID：在 giscus.app 输入 MzMedia/MzMedia.github.io，选择讨论分类（如 General），将生成的 data-category-id 填入组件配置即可全站点亮！
