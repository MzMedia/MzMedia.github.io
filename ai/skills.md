# 📦 Skill 脚本动态物化沙箱

为了让 AI 智能体拥有动态扩展的计算能力，MzMedia 设计了基于 **Skill 物化沙箱 (`Ai1SkillToolFactory`)** 的技能管理引擎。

---

## 1. 架构与运行机制

```text
 ┌────────────────────────────────────────────────────────┐
 │ 后台维护技能代码树 (ai1_skill & ai1_skill_file 表)     │
 │  · Python 数据拟合脚本 / Shell 诊断命令 / JS 计算函数   │
 └───────────────────────────┬────────────────────────────┘
                             │
                             ▼ (智能体被调用时)
 ┌────────────────────────────────────────────────────────┐
 │ 动态物化沙箱 (Ai1SkillToolFactory)                     │
 │  · 在磁盘安全隔离目录创建临时文件树                     │
 │  · 动态组装为标准 Function / Tool                      │
 └───────────────────────────┬────────────────────────────┘
                             │
                             ▼
 ┌────────────────────────────────────────────────────────┐
 │ 隔离执行与结果回收                                     │
 │  · 限时执行、内存限额、禁止敏感系统调用                │
 │  · 格式化输出 JSON 结果回填给大模型                    │
 └────────────────────────────────────────────────────────┘
```

---

## 2. 核心应用场景

1. **工业公式动态计算**：例如蒸汽锅炉焓值计算、水管管压流速拟合、电力三相不平衡度动态推导；
2. **多源数据清洗**：针对上游第三方历史 CSV 数据执行即时清洗与格式归一化；
3. **自动化维保巡检脚本**：定期自动执行连通性 ping 测试、ZLMediaKit 端口吞吐统计并生成巡检摘要日报。
