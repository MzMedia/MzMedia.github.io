# 📈 时序数据运维 RAG 智能体

传统设备维保排查依赖老技工的经验，面对海量的报警日志和波动曲线往往无从下手。MzMedia 结合 **检索增强生成 (RAG)** 与 **时序时相分析**，打造了专为工业现场服务的 AI 运维智能体。

---

## 交互全流程示例

```text
工程师提问:
"2号注塑机昨天下午为什么突发停机？可能是什么原因导致的？"
```

1. **意图识别与上下文提取**：
   - AI Agent 识别目标设备（`2号注塑机`）与目标时间段（`昨天下午 12:00 ~ 18:00`）；
2. **多源数据融合调用 (Tool Calling)**：
   - 调用 MCP Tool 查询 TDengine：检索该机台的加热圈温度、液压油泵压力、主电机电流曲线；
   - 调用系统告警接口：检索是否有断偶告警或压力超限告警记录；
3. **企业知识库检索 (RAG Vector Store)**：
   - 根据“注塑机过热保护”等关键词在企业维护手册知识库（`ai1_knowledge_base`）中召回维保规程（如《注射机热流道温控箱常见故障排查 SOP》）；
4. **归因推理与建议生成**：
   - AI 智能体对比温度曲线突变点与告警时间，生成结构化诊断报告：
     > **排查结论**：昨天 14:23 发现 3 号加热区温度在 2 分钟内从 185℃ 骤升至 260℃，触发系统过温硬件联锁停机。  
     > **诱因分析**：结合知识库 SOP，固态继电器 (SSR) 击穿常通的概率为 85%，热电偶开路漂移概率为 15%。  
     > **建议措施**：断电检查 3 号固态继电器触点状态，若击穿请从 WMS 仓库调拨配件（型号: SSR-40DA）更换。
5. **一键工单派发**：
   - 工程师确认后，AI 直接联动 MES 与 Flowable 生成派工单推送到维保工程师手机端。
