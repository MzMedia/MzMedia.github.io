# 🤖 AIoT 智能中枢概述

`yudao-module-ai1-springai` 是 MzMedia 的人工智能核心套件。该模块深度整合了 **Spring AI 1.1+** 与 **Anthropic Model Context Protocol (MCP)** 标准，致力于将前沿生成式 AI（LLM）切实落地到工业物联网和安防音视频运维场景中。

---

## 核心设计理念

传统的 AI 对话系统通常仅停留在文本问答层面，无法感知工业现场物理实况，也无法操作实际生产设备。MzMedia 实现了：
1. **多大模型支持**：支持统一对接 OpenAI、DeepSeek、Claude、Gemini、通义千问、MiniMax 等国内外 18+ 主流大模型；
2. **标准工具暴露 (MCP Tools)**：将设备时序查询、告警检索、视频抓拍、工单下发封装为标准化 MCP 工具，赋予 AI 智能体“手”和“眼”；
3. **时序运维 RAG 体系**：融合 TDengine 遥测曲线与企业维保知识库，实现设备异常归因与智能化排障建议；
13: 4. **工业私有协议智能逆向**：借助大模型的代码推理能力，输入十六进制非标报文即可自动推导报文结构并生成 Netty 驱动代码。
