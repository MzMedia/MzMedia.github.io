# 🎥 视频监控中心概述

`yudao-module-media` 是 MzMedia 专为解决工业安防、园区监控与物联网跨系统视频联动而设计的流媒体中枢。

---

## 核心能力矩阵

1. **国标 GB/T 28181-2016/2022 全栈支持**：
   - 支持主流品牌（海康威视、大华股份、宇视科技等）IPC 网络摄像机、NVR 硬盘录像机无缝通过 SIP 协议注册接入；
   - 覆盖设备注册鉴权、心跳保活、通道目录检索、状态查询与报警通知。
2. **ZLMediaKit 流媒体集群纳管**：
   - 自动分配 RTP 动态接收端口（`30000-30500`）；
   - 将设备推送的 PS/RTP 流实时解复用并转换为 **WebRTC、HTTP-FLV、WS-FLV、HLS** 多协议格式；
   - 提供 REST API 与 Webhook 回调机制（推流鉴权、播放统计、无人观看自动停流）。
3. **低延迟网页点播与云台控制**：
   - 深度集成 **Jessibuca** 播放器，延迟稳定低于 1 秒；
   - 网页端提供全功能 PTZ 云台控制轮盘，支持八向转动、焦距调整、光圈变倍与 **0x81 预置位调用**；
   - 支持浏览器麦克风声音采集并通过 G.711A/U 进行**双向语音对讲**。
4. **与物联网（IoT）深度跨域联动**：
   - 传感器（烟感、温度、周界红外等）上报异常时，秒级发布系统事件 `IotMediaLinkageEvent`；
   - 驱动就近球机快速对准报警现场并触发快照抓拍，告警消息卡片直达移动端。
