# 📌 MzMedia 平台简介

## 什么是 MzMedia？

**MzMedia** 是一款专为**中小企业量身打造的企业级 AI 驱动物联网与视频融合平台**。

平台基于成熟的 `ruoyi-vue-pro`（master-jdk25 / Java 21 / Spring Boot 3.5 & 4.1）企业级底座深度孵化，深度融合了 **物联网（IoT）感知接入**、**安防音视频（GB/T 28181 / WebRTC）流媒体中枢** 与 **生成式 AI（Spring AI / MCP）智能体** 技术。

## 🎯 核心使命与愿景

中小企业在数字化改造与工业互联网落地过程中，往往面临：
- **买得起硬件，建不起平台**：商业 IoT 软件授权动辄数十万，定制二次开发周期长；
- **系统各自为政，数据烟囱林立**：PLC 数据在工控上位机、视频在 NVR 录像机、工单在微信群、项目交接在 Excel，互相孤立割裂；
- **老旧设备协议杂乱**：Modbus、私有 TCP 报文、各类非标串口，缺乏标准驱动，接入调试需要资深工程师耗费数周；
- **看数据与看现场脱节**：传感器报警不知道现场实况，安防摄像头沦为“事后查录像”，无法实现防患于未然。

**MzMedia 的使命就是彻底打破这些壁垒**：
1. **开源可商用**：基于宽松协议，单机支持 Docker Compose 快速体验，集群支持分布式高可用；
2. **AI 赋能跨协议接入**：借助大模型自动推导私有报文格式，一键生成 Netty 解码器；
3. **同屏音视频深度融合**：传感器超限秒级驱动 GB28181 云台球机转动预置位并抓拍推流，真正实现“看数据”与“看现场”合二为一；
4. **全业务链闭环**：从工程立项 (PMS)、备件调拨 (WMS)、设备监控 (IoT)、异常预警 (MES) 到工作流审批 (Flowable)，一套底座彻底拉通业务。
