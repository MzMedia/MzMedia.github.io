# 🏭 MES 制造执行与设备工单

`yudao-module-mes` 是 MzMedia 面向数字化车间打造的制造执行与设备运维系统，深度融合了物联网传感器报警与现场生产协同。

---

## 1. 六大子系统功能矩阵

| 子模块 | 标识 | 核心定位与业务价值 |
| :--- | :--- | :--- |
| **主数据管理** | `md` | 物料 BOM 清单、SOP 标准作业指导书、SIP 标准检验规程、车间工位工作站与编码规则定义。 |
| **排产与日历** | `cal` | 生产日历、早中夜三班轮转排程、法定节假日规则与班组人员分配。 |
| **设备台账与维保** | `dv` | **设备全生命周期档案、点检计划、保养记录；与 IoT 告警自动联动生成维修工单。** |
| **生产制造流转** | `pro` | 工艺路线设计、生产工单与流转卡（Card）、工序派工、报工流水与安灯（Andon）一键呼叫。 |
| **全流程质检** | `qc` | 来料检验 (IQC)、过程检验 (IPQC)、出货质检 (OQC)、质检方案与缺陷代码归因库。 |
| **车间物料条码** | `wm` | 生产领退料、物料单品 SN 序列号追踪、批次追溯与线边仓动态盘点。 |

---

## 2. IoT 设备告警与车间工单闭环

当安装在加工中心机床上的振动传感器或温升传感器检测到持续超出警戒阈值时：
1. `yudao-module-iot` 触发场景联动规则；
2. 自动调用 `yudao-module-mes` 中的设备维保接口，在 `dv` 模块自动生成一张“紧急维修工单”；
3. 同时触发车间 **Andon 安灯呼叫**，生产调度大屏对应工位亮红灯；
4. 生产主管在审批通过后，系统自动在 `pro` 模块将该工位的后续待加工批次转移至备用产线，避免批量废品。
