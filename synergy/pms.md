# 📋 PMS 物联网工程项目交付

`yudao-module-pms` 是 MzMedia 面向中小企业工程交付与施工团队打造的项目全生命周期管理系统。

---

## 1. 工程项目交付五步法

```text
 ┌────────────────────────────────────────────────────────┐
 │ 1. 立项与交付节点规划                                  │
 │    建立工程项目、配置勘测、布线、通网、终验等关键里程碑│
 └───────────────────────────┬────────────────────────────┘
                             │
                             ▼
 ┌────────────────────────────────────────────────────────┐
 │ 2. 物料预占与设备出库 (联动 WMS)                       │
 │    项目 BOM 物料清单审核通过后，自动锁定仓库传感器库存  │
 └───────────────────────────┬────────────────────────────┘
                             │
                             ▼
 ┌────────────────────────────────────────────────────────┐
 │ 3. 设备通电入网与绑定 (联动 IoT)                       │
 │    施工人员上电，网关通过激活密钥自动注册并归属到项目树 │
 └───────────────────────────┬────────────────────────────┘
                             │
                             ▼
 ┌────────────────────────────────────────────────────────┐
 │ 4. 敏捷工作项协同与缺陷排查                           │
 │    现场布线任务看板、施工拍照打卡、设备通信掉线 Bug 追踪 │
 └───────────────────────────┬────────────────────────────┘
                             │
                             ▼
 ┌────────────────────────────────────────────────────────┐
 │ 5. 竣工验收与知识资产归档 (沉淀至 KB)                  │
 │    CAD 图纸、接线端子拓扑、验收单据在线归档，转为运维期 │
 └────────────────────────────────────────────────────────┘
```

---

## 2. 敏捷任务看板与企业知识库 (KB)

- **工作项三级分类**：支持**需求 (Requirement)**、**任务 (Task)** 与 **缺陷 (Bug)** 独立状态流转；
- **交付进度大屏**：直观展示每个工程站点的设备入网率、在线率、施工工时消耗与人员饱和度；
- **工程知识库 (KB)**：多层级目录归档施工布线规范、PLC 点位对照表与设备现场勘测照片，支持权限隔离与外部分享。
