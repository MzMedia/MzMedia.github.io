📐 统一物模型 (TSL) 规范 ​

物模型（Thing Specification Language, TSL）是对物理世界设备数字化表述的标准语言。无论底层采用哪种传输协议，MzMedia 均将设备抽象为标准的三大维度要素：

1. 物模型三大核心要素 ​

要素一：属性 (Property) ​

  • 表示设备当前的测量值或静态参数；
  • 包含只读（r）与读写（rw）权限；
  • 支持丰富的数据类型：int, float, double, string, bool, enum, array, struct；
  • 支持定义数值上下限、单位（如 ℃, MPa, V, A）以及步长。

要素二：服务 (Service) ​

  • 平台向设备下发的控制指令，包含入参（Input Parameters）与出参（Output Parameters）；
  • 支持同步执行模式（等待设备返回结果）与异步执行模式（下发后通过设备事件异步回调确认）。

要素三：事件 (Event) ​

  • 设备运行过程中主动向平台上报的特定事件；
  • 分为三个事件等级：
    • 信息 (Info)：常规事件（如“定时自检正常”、“固件升级开始”）；
    • 告警 (Warn)：阈值告警（如“液位偏高”、“滤波网即将到期”）；
    • 故障 (Error)：严重事件（如“电机堵转”、“主板过温停机”）。

3. 设备影子 (Device Shadow) ​

在弱网或移动应用场景中，设备并不总是在线。MzMedia 提供了设备影子机制：

  • 缓存设备最新的物理属性值（Reported 状态）；
  • 缓存平台期望下发但设备尚未联机确认的控制值（Desired 状态）；
  • 设备重新上线时，网关自动将差量变更推送到设备端并清空影子指令。

为什么提示 "giscus is not installed on this repository"？

Giscus 是基于 GitHub Discussions 的开源评论组件。因为当前仓库 MzMedia/MzMedia.github.io 尚未在 GitHub 启用 Discussions 功能或未授权 Giscus App，直接加载会提示该错误。

🛠️ 仓库管理员 2 分钟极速开通指引：

  1. 开启 Discussions：访问 GitHub 仓库设置 (Settings) ，找到 Features 勾选 Discussions。
  2. 授权 Giscus App：打开 github.com/apps/giscus ，点击 Install 并授权给仓库 MzMedia/MzMedia.github.io。
  3. 获取 Category ID：在 giscus.app 输入 MzMedia/MzMedia.github.io，选择讨论分类（如 General），将生成的 data-category-id 填入组件配置即可全站点亮！
