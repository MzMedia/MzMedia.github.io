## 2. 生产关键参数调优

1. **JVM 启动参数优化 (JDK 21+)**：
   ```bash
   java -server -Xms4g -Xmx4g -XX:+UseG1GC -XX:MaxGCPauseMillis=200 -jar yudao-server.jar
   ```
2. **操作系统网络与文件描述符**：
   - 工业长连接与流媒体推流需要占用大量文件描述符，在 `/etc/security/limits.conf` 中调整：
     ```text
     * soft nofile 655350
     * hard nofile 655350
     ```
3. **ZLMediaKit RTP 端口范围放行**：
   - 生产环境中必须在防火墙放行 UDP 与 TCP 的 `30000-30500` 端口范围，确保外部摄像机能够稳定推流到集群。
